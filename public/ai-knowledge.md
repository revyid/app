## Features
- **GitHub API Proxy** — Access GitHub data (profiles, repos, activity) via REST API
- **URL Shortener** — Create short links with custom slugs, track clicks
- **Code Sandbox** — Run JavaScript, Python, TypeScript, cURL in-browser
- **curl-ts** — Parse and execute curl commands in TypeScript
- **Dashboard** — Manage API keys and short URLs

## Tech Stack
Next.js 15, React 19, TypeScript, Tailwind CSS, Supabase (PostgreSQL), Vercel

## Auth
Supabase Auth with GitHub, Google, and Passkeys. Separate dashboard app at dashboard.revy.my.id.
