# Plan: Rapikan Sidebar + Footer di Semua Page

## Problem
- Sidebar NAV arrays beda antara `docs/layout.tsx` dan `dashboard/layout.tsx`
- Privacy/Terms ada di docs sidebar (seharusnya di footer)
- Naming: "Revy" bukan "Revy" di beberapa tempat
- Tidak ada footer di website

## Research: How other websites do it
Looking at Vercel, Linear, etc:
- **Sidebar** = primary nav only (Home, Dashboard, Docs, etc.)
- **Footer** = legal pages (Privacy, Terms, Contact, etc.)
- **Consistent sidebar** across all authenticated pages

## Changes

### 1. Shared NAV constant
Buat `src/lib/nav.ts` — single source of truth untuk NAV items, di-import oleh semua layout.

### 2. Remove Privacy/Terms dari docs sidebar
Privacy dan Terms bukan dokumentasi — mereka di footer.

### 3. Buat Footer component
`src/components/layout/Footer.tsx` — ada Privacy, Terms, Guide, copyright.

### 4. Add Footer ke semua layout
- `src/app/(main)/layout.tsx` → render Footer
- `src/app/dashboard/layout.tsx` → render Footer
- `src/app/docs/layout.tsx` → render Footer

### 5. Sync sidebar NAV
Both `docs/layout.tsx` dan `dashboard/layout.tsx` import dari `src/lib/nav.ts`.

### 6. Fix naming
Cek semua file — "Revy" consistently.

## Files to modify

- `src/app/(main)/layout.tsx`
